# Flow State logo exports

Exported from the canonical logo in the FlowState Paper document on September 21, 2026.

- `flowstate-logo.png`: 800 × 800 transparent PNG. Use this standalone mark in the app and on the web.
- `flowstate-logo-master.png`: 1024 × 1024 presentation artboard, including its background and margins. Do not use this as a template icon.

Paper source: https://app.paper.design/file/01M2Z4VKQPCNBE4G7GJHQJ8TA6/p-1-0

The source mark is raster artwork; these are original PNG exports, not a traced SVG. The Mac menu bar loads the transparent mark as a native 22-point `NSImage` template so macOS chooses its color. Keep the gaps between waves transparent.
